HERO IMAGE
==========
The landing hero shows /public/hero.jpg if it exists, and falls back to
hero-fallback.svg (an abstract workspace illustration) if it does not.

To use a real photograph, drop a file named exactly:

    frontend/public/hero.jpg

No code change is needed — the page picks it up on refresh.

Suggested free sources (no attribution required):
  - unsplash.com  : search "team brainstorming sticky notes"
  - pexels.com    : search "office collaboration whiteboard"

Recommended: landscape, at least 1600x900, under ~400 KB.
